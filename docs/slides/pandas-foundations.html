A request about 794 talks

You receive a table with 794 General Conference talks and 14 variables.

Find the five talks from 2018 through 2020 with the largest word counts. Show the title, speaker, conference, and word count.

What must your code do before you can answer?

Planned time: 2 minutes.

Read the request without showing code. Ask students to name the decisions hidden inside it. Listen for understanding rows and columns, filtering years, choosing columns, sorting, and keeping five rows.

Think, pair, share

  1. What does one row need to represent?
  2. Which variables matter for the request?
  3. Which observations qualify?
  4. How should the qualifying rows be ordered?
  5. What would you check before reporting the answer?

Planned time: 4 minutes.

Give students about 45 seconds to think and 90 seconds to compare. During the share, collect one answer for each question. Keep the discussion at the level of table operations rather than pandas syntax.

A data question becomes table operations

  • Understand: identify the observational unit and variables.
  • Select: keep the columns needed for the answer.
  • Filter: keep the rows that satisfy the conditions.
  • Order: arrange the rows so the requested cases come first.
  • Check: confirm the shape and meaning of the result.

pandas gives these operations a vocabulary.

Planned time: 2 minutes.

Use this as the debrief for the discussion. The five verbs organize the rest of the lecture. Point out that the order of selecting and filtering can vary, but every operation should serve the question.

What pandas adds

  • Row and column labels carry meaning into the code.
  • Each column can have its own data type.
  • Labels support selection and automatic alignment.
  • Table methods express common data tasks directly.

Combining conditions

mask = (
    talks["year"].between(2019, 2020)
    & (talks["session"] == "sunday-morning")
    & talks["num_words"].between(1400, 1700)
)
  • & means elementwise AND.
  • | means elementwise OR.
  • ~ reverses a Boolean condition.
  • Parentheses make each comparison explicit.

Planned time: 3 minutes.

Explain why ordinary Python and, or, and not do not make one decision per row. Do not dwell on operator precedence rules. Teach parentheses as the readable standard.

Helpers express common conditions

Inclusive range

talks["year"].between(2018, 2020)

    "sunday-morning",

Planned time: 2 minutes.

Show the longer equivalent only verbally if useful. These helpers often express the data question more clearly than a long chain of repeated comparisons.

Three filtering mistakes

# Python asks for one truth value
condition_1 and condition_2

# The comparisons need parentheses
talks["year"] >= 2018 & talks["year"] <= 2020

# This assignment targets a temporary result
talks[talks["year"] >= 2018]["recent"] = True

Use vectorized operators, parenthesized comparisons, and one .loc[] assignment.

Planned time: 2 minutes.

Do not ask students to memorize warning messages. Emphasize the reliable pattern. With pandas 3 Copy-on-Write, chained assignment never updates the original object.

Sorting asks a separate question

Filtering asks:

Which rows qualify?

Sorting asks:

In what order should the qualifying rows appear?

recent_talks.sort_values("num_words")

Ascending order is the default.

Planned time: 2 minutes.

Connect sorting to the opening request. The qualifying rows do not change. Only their displayed order changes.

Largest values first

longest_recent = (
    recent_talks
    .sort_values("num_words", ascending=False)
    .head(5)
)
  • ascending=False places larger values first.
  • head(5) keeps the first five rows after sorting.
  • sort_values() returns a reordered DataFrame.

Planned time: 2 minutes.

Ask what would happen if head(5) came before sorting. It would return the largest values only by accident. The sequence of operations carries meaning.

  2. Within each year, put longer talks first.

New columns use vectorized expressions

recent_talks = talks.loc[recent_mask].copy()

recent_median = recent_talks["num_words"].median()

recent_talks["above_recent_median"] = (
    recent_talks["num_words"] > recent_median
)

The comparison produces one new value for every row.

Planned time: 2 minutes.

The explicit copy communicates that recent_talks is now an independent working table. pandas 3 Copy-on-Write already prevents edits to this subset from changing talks, but the explicit copy also works in earlier versions and remains readable.

A defensible translation

mask = (
    talks["year"].between(2019, 2020)
    & (talks["session"] == "sunday-morning")
    & talks["num_words"].between(1400, 1700)
)

selected = talks.loc[
    mask,
    ["talk_name", "speaker", "conference", "year", "num_words"]
]

result = selected.sort_values(
    ["year", "num_words"],
    ascending=[False, False]
)

pandas’ organizing idea

A DataFrame keeps values connected to labels, and a clear analysis translates a question into inspectable table operations.

  • Know what one row represents.
  • Predict the type and shape of each intermediate result.
  • Check that the final rows and columns answer the original question.

End with the reasoning habit rather than a list of methods. The next lesson can build on this foundation by asking how to summarize separate groups of rows.
